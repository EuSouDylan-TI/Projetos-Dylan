# 📦 Sistema de  Cadastro de Produtos, Usuario e Genero [EM Desenvolvimento...]

Aplicação Desktop desenvolvida em **Java** com interface gráfica moderna construída no **SceneBuilder (JavaFX)** e persistência de dados no **MySQL**. O sistema permite Criar Sua Conta E Procurar Suas Vagas De Emprego.

---
## Nao Esta Completo

## 🛠️ Tecnologias e Ferramentas Utilizadas

- **Linguagem:** Java (JDK)
- **Interface Gráfica:** JavaFX & SceneBuilder (FXML)
- **Banco de Dados:** MySQL
- **Conectividade:** JDBC (Java Database Connectivity)
- **IDEs / Ferramentas:** VS Code / SceneBuilder

---

## ✨ Funcionalidades

- [x] **Cadastro de Usuários:** Cadastro e Login.
- [x] **Cadastro de Empresas:** Cadastro Tipo Empresa E Login.
- [x] **Cadastro de Vagas:** Cadastro, Listagem De Todas As Vagas Para Os Usuarios.
- [x] **Comunicaçao Empresa e Usuario:** Permitir Conversar As Empresas E Usuarios.
- [x] **Integração com MySQL:** Operações completas de CRUD (Create, Read, Update, Delete).
